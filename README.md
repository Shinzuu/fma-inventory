# FMA Chapter 6 — Inventories (class-test guide)

A single-page study guide for **Financial & Managerial Accounting, Chapter 6: Inventories**.

**📖 Read it here → <https://shinzuu.github.io/fma-inventory/>**

## What's inside

| | |
|---|---|
| **LO 1** | Classifying inventory (merchandiser vs manufacturer) · why each system takes a physical count · FOB shipping point vs FOB destination · consigned goods · the Hasbeen Co. correction |
| **LO 2** | Cost = expenditures to acquire and ready for sale · specific identification (Crivitz) · FIFO, LIFO and average-cost worked on the Houston Electronics data · comparative income statements · income, balance sheet and tax effects · LIFO conformity rule |
| **LO 3** | Causes of inventory errors · income-statement and balance-sheet effect tables · the two-period reversal · the Visual Company case |
| **LO 4** | Presentation and required disclosures · inventory turnover and days in inventory |
| **Appendix 6A** | FIFO, LIFO and moving-average under a **perpetual** system, and why only FIFO matches the periodic answer |
| **Worked problems** | **P6.5A** (periodic) and **P6.8A** (perpetual) solved in full, both matching the textbook check figures |
| **Practice** | 15 multiple-choice, 25 fill-in-the-blanks, 9 computation drills, 31 question cards, night-before checklist |

Light/dark theme, works on a phone, no build step to read it.
